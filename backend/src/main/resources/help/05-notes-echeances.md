# Notes et échéances

## Notes de dossier

Chaque dossier dispose d'une section **"Notes"** pour consigner vos observations, stratégies ou commentaires. Les notes sont privées à votre workspace. Cliquez sur **"Ajouter une note"** pour créer une nouvelle note.

## Modifier ou supprimer une note

Cliquez sur une note pour la modifier. Le bouton de suppression permet d'effacer définitivement une note.

## Échéances

La section **"Échéances"** d'un dossier permet de suivre les dates importantes :
- Délais de procédure
- Audiences
- Délais de réponse
- Dates contractuelles

## Ajouter une échéance

Cliquez sur **"Ajouter une échéance"**, renseignez le titre, la date et une description optionnelle. Les échéances proches sont mises en évidence.

## Modifier ou supprimer une échéance

Cliquez sur une échéance pour la modifier ou la supprimer depuis son menu d'options.
