# Analyse IA

## Lancer une analyse

Depuis le détail d'un dossier, cliquez sur **"Lancer l'analyse"**. L'analyse est asynchrone : elle s'exécute en arrière-plan et vous pouvez continuer à travailler pendant ce temps.

## Suivi de l'analyse

Une barre de progression indique l'état de l'analyse : en attente, en cours, terminée ou en erreur. La page se met à jour automatiquement.

## Ce que produit l'analyse

L'analyse IA produit :
- **Faits** : les faits clés extraits des documents
- **Points juridiques** : les questions de droit identifiées
- **Risques** : les risques potentiels pour votre client
- **Questions ouvertes** : les points qui méritent approfondissement

## Niveaux d'analyse

L'analyse fonctionne en trois niveaux :
1. **Analyse des chunks** : chaque extrait de document est analysé individuellement
2. **Analyse des documents** : synthèse par document
3. **Analyse du dossier** : synthèse globale de l'ensemble du dossier

## Relancer une analyse

Si un document a été modifié ou si vous souhaitez relancer l'analyse, utilisez le bouton **"Relancer l'analyse"** depuis le menu du dossier.

## Questions IA interactives

Pendant ou après l'analyse, l'IA peut poser des questions à l'avocat pour affiner sa compréhension. Ces questions apparaissent dans la section **"Questions IA"** du dossier. Répondez-y pour améliorer la qualité de l'analyse.

## Vérification de procédure

L'application peut vérifier automatiquement si les procédures requises ont été respectées dans le dossier (délais de convocation, mentions obligatoires, etc.).
