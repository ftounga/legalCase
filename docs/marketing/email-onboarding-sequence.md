- **Brevo** (ex-Sendinblue) — API transactionnelle, automation gratuite jusqu'à 300 emails/jour, interface française, conforme RGPD
- Alternative : **Resend** (developer-friendly, API simple) + **React Email** pour les templates

| M-20 | Création de compte confirmée | Immédiat |

| M-22 | M-21 envoyé | J+5 |
| M-23 | Trial expire dans 48h | J+12 |
| M-24 | Trial expiré ET pas d'abonnement actif | J+15 |

- M-22 : toujours envoyer (feature découverte)
- M-23/M-24 : ne pas envoyer si l'utilisateur a souscrit un plan payant
