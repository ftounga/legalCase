# Mini-spec — F-222 / SF-222-02 — Outil TGD (téléphone grave danger)

## Identifiant
`F-222 / SF-222-02` — tool_id `F-FA-TGD` (Famille FR)

## Objectif (1 phrase)
Évaluer l'éligibilité d'une victime de violences au dispositif Téléphone Grave Danger (art. 41-3-1 CPP) — l'outil **conseille** l'avocat ; l'attribution relève du procureur de la République.

## Comportement (branche `default`)
Entrées : `violencesAvereesOuVraisemblables` (bool), `interdictionContactProcedure` (bool : ordonnance protection / contrôle judiciaire / SME / condamnation interdisant le contact), `nonCohabitation` (bool), `consentementVictime` (bool), `dangerGrave` (bool).
Logique : éligibilité TGD = `dangerGrave` ET `violencesAveréesOuVraisemblables` ET `interdictionContactProcedure` ET `nonCohabitation` ET `consentementVictime`.
Verdict : `ELIGIBLE_TGD` (tous remplis) / `ELIGIBLE_SOUS_RESERVE` (interdiction de contact non encore prononcée → conseiller de la demander d'abord, ex. ordonnance de protection F-FA-14) / `NON_ELIGIBLE` (un critère dur manquant) + liste des critères manquants + mention « attribution par le procureur ».

## Contrat API
`POST /api/v1/case-files/{caseFileId}/tgd/analyze`
- Request `TgdAnalyzeRequest` : `{ violencesAvereesOuVraisemblables, interdictionContactProcedure, nonCohabitation, consentementVictime, dangerGrave }` (tous bool)
- Response `TgdAnalyzeResponse` : `{ verdict, criteresManquants:string[], basesJuridiques:string[], messages:string[] }`

## Critères d'acceptation
- [ ] 3 verdicts ; `criteresManquants` listé pour NON_ELIGIBLE / SOUS_RESERVE.
- [ ] `ELIGIBLE_SOUS_RESERVE` ⇒ renvoi vers `F-FA-14-ordonnance-protection` quand l'interdiction de contact manque.
- [ ] Message explicite « décision = procureur » (l'outil ne décide pas).
- [ ] Champs pré-remplis IA ; isolation workspace testée.
